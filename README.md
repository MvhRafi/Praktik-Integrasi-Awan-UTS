# 🌿 Proyek UTS IoT: Tanaman yang Curhat

Sistem pemantauan dan interaksi tanaman berbasis IoT yang mempersonifikasikan kondisi tanaman menjadi kalimat "curhatan" dan ekspresi suasana hati secara *real-time*. Sistem ini memanfaatkan **ESP32** sebagai *edge device* pembaca data telemetri, **Supabase Cloud** sebagai basis data terpusat & API Gateway, **GUI Web** interaktif 2-kolom presisi gaya Canva, serta **Skrip Python** untuk pencadangan data lokal (SQLite & CSV).

---

## 🚀 Fitur Utama

- **Real-Time Telemetry & Personifikasi Mood**: Menampilkan nilai kelembapan tanah, intensitas cahaya (Lux), dan sisa debit air teko beserta animasi emoji & kalimat curhatan tanaman.
- **Interaksi Penyiraman 2-Arah**: Tombol "SIRAM" di GUI Web memicu antrean perintah `PENDING` di cloud yang dibaca oleh ESP32 (*polling*), mereset kelembapan ke 100%, mengurangi kapasitas air teko, dan memperbarui status menjadi `DONE`.
- **Desain GUI Web Presisi**: Layout 2-kolom responsif dengan Tailwind CSS, animasi pergantian status penyiram air (`pemadam_diam.png` vs `pemadam_siram.png`), serta linimasa riwayat curhatan.
- **Robust Connection & Empty State Handling**:
  - Indikator status koneksi (*🟢 Terhubung* vs *🔴 Terputus*) dan banner peringatan otomatis jika jaringan internet terganggu.
  - Tampilan cadangan (*fallback UI*) yang rapi jika database di cloud masih kosong.
- **Keamanan REST API (RLS Enabled)**: Integrasi autentikasi Row Level Security (RLS) Supabase menggunakan *Service Role Secret Key* pada ESP32 untuk mencegah *unauthorized access* (error 401/403).
- **Auto Sync / Local Backup**: Skrip Python otomatis yang menyinkronkan data cloud Supabase ke database lokal **SQLite (`backup_tanaman.db`)** dan berkas **CSV (`backup_kondisi_tanaman.csv`)**.

## ⚙️ Persiapan & Instalasi

### 1. Konfigurasi Database Supabase Cloud
1. Buka [Dashboard Supabase](https://supabase.com/dashboard) dan buat proyek baru.
2. Buka **SQL Editor** (`_>`), lalu jalankan skrip SQL berikut untuk membuat tabel & mengatur Policy RLS:

```sql
SET timezone = 'Asia/Jakarta';

-- 1. BUAT TABEL kondisi_tanaman
CREATE TABLE IF NOT EXISTS kondisi_tanaman (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    dibuat_pada TIMESTAMPTZ DEFAULT NOW(), -- Menggunakan TIMESTAMPTZ agar mencakup offset +07:00
    kelembapan INT4 NOT NULL,
    cahaya INT4 NOT NULL,
    suasana_hati TEXT NOT NULL,
    curhatan TEXT NOT NULL
);

-- 2. BUAT TABEL perintah (Untuk Kendali Tombol "Siram")
CREATE TABLE IF NOT EXISTS perintah (
    id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    dibuat_pada TIMESTAMPTZ DEFAULT NOW(),
    aksi TEXT NOT NULL,             -- Contoh: "SIRAM"
    status TEXT DEFAULT 'PENDING'    -- Contoh: "PENDING" atau "DONE"
);

-- 3. AKTIFKAN ROW LEVEL SECURITY (RLS) - (Syarat Wajib UTS)
ALTER TABLE kondisi_tanaman ENABLE ROW LEVEL SECURITY;
ALTER TABLE perintah ENABLE ROW LEVEL SECURITY;

-- 4. BUAT POLICY RLS UNTUK TABEL kondisi_tanaman
CREATE POLICY "Izinkan Baca kondisi_tanaman" 
ON kondisi_tanaman FOR SELECT 
TO anon, authenticated 
USING (true);

CREATE POLICY "Izinkan Tambah kondisi_tanaman" 
ON kondisi_tanaman FOR INSERT 
TO anon, authenticated 
WITH CHECK (true);

-- 5. BUAT POLICY RLS UNTUK TABEL perintah
CREATE POLICY "Izinkan Baca perintah" 
ON perintah FOR SELECT 
TO anon, authenticated 
USING (true);

CREATE POLICY "Izinkan Tambah perintah" 
ON perintah FOR INSERT 
TO anon, authenticated 
WITH CHECK (true);

CREATE POLICY "Izinkan Update perintah" 
ON perintah FOR UPDATE 
TO anon, authenticated 
USING (true) 
WITH CHECK (true);
```

3. Salin **Project URL**, **Anon Key**, dan **Service Role Secret Key** dari menu *Project Settings $\rightarrow$ API*.

---

### 2. Konfigurasi ESP32 (`tanaman_curhat.ino`)
1. Buka berkas `tanaman_curhat.ino` di Arduino IDE.
2. Pastikan library **ArduinoJson** (`v6.x`) dan **HTTPClient** telah terinstal.
3. Sesuaikan SSID Wi-Fi, Password, URL Supabase, dan Service Role Secret Key:

```cpp
const char* WIFI_SSID     = "NAMA_WIFI_ANDA";
const char* WIFI_PASSWORD = "PASSWORD_WIFI";

const char* SUPABASE_URL    = "[https://xxxx.supabase.co](https://xxxx.supabase.co)";
const char* SUPABASE_KEY    = "ANON_KEY_ANDA";
const char* SUPABASE_SECKEY = "SERVICE_ROLE_SECRET_KEY_ANDA";
```
4. Upload program ke board ESP32 (Baud rate Serial Monitor: `115200`).

---

### 3. Konfigurasi GUI Web (`gui/script.js`)
1. Buka berkas `gui/script.js`.
2. Masukkan URL dan Anon Key Supabase Anda:

```javascript
const SUPABASE_URL = "[https://xxxx.supabase.co](https://xxxx.supabase.co)"; 
const SUPABASE_KEY = "ANON_KEY_ANDA"; 
```
3. Buka berkas `gui/index.html` langsung melalui browser atau gunakan extension *Live Server* di VS Code.

---

### 4. Konfigurasi Skrip Backup Python (`backup_sqlite.py`)
1. Pastikan Python 3.x dan modul `requests` sudah terpasang di komputer Anda:
   ```bash
   pip install requests
   ```
2. Buka `backup_sqlite.py` dan sesuaikan kredensial Supabase.
3. Jalankan skrip backup:
   ```bash
   python backup_sqlite.py
   ```

## 🛠️ Penanganan Kendala (Troubleshooting)

- **HTTP Error 401 Unauthorized pada ESP32**:
  - *Penyebab*: Policy RLS Supabase memblokir request atau header autentikasi salah.
  - *Solusi*: Pastikan kedua header pada fungsi HTTP ESP32 (`sendToSupabase`, `checkWaterCommand`, `updateCommandStatus`) menggunakan `SUPABASE_SECKEY`:
    ```cpp
    http.addHeader("apikey", SUPABASE_SECKEY);
    http.addHeader("Authorization", String("Bearer ") + SUPABASE_SECKEY);
    ```
- **GUI Tidak Update / Data Kosong**:
  - *Penyebab*: URL/Anon Key di `script.js` belum disesuaikan atau data di Supabase belum ada.
  - *Solusi*: Buka tab Console pada Developer Tools browser (`F12`), amati log error, dan pastikan ESP32 telah berhasil melakukan pengiriman POST pertama.
